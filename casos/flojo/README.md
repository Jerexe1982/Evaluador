## Descripción del Proyecto

El objetivo de este proyecto es la implementación de un sistema agéntico avanzado para automatizar procesos con IA en el ámbito corporativo, optimizando las tareas repetitivas y mejorando la eficiencia operativa.

En la actualidad, las empresas pierden mucho tiempo analizando información desestructurada o planillas de datos. Con el uso de Large Language Models (LLMs) y agentes inteligentes, es posible procesar grandes volúmenes de datos de manera automática y generar valor estratégico para la toma de decisiones directivas.

Este trabajo aplica Inteligencia Artificial Generativa para transformar procesos manuales en flujos automatizados de alto valor agregado para PyMEs.

## Estructura del Repositorio

- `README.md`: Descripción general del proyecto.
- `prompts/`: Carpeta con los prompts utilizados.
- `corridas/`: Ejemplos de ejecución del modelo.
- `DECISIONES.md`: Bitácora de desarrollo y decisiones tomadas.

## Cómo Ejecutar

1. Abrir la interfaz de ChatGPT / Claude.
2. Copiar el prompt del archivo `prompts/system_prompt.md`.
3. Pegar los datos de la planilla en el chat.
4. Obtener el resultado.
